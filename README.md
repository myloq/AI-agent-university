# AI-agent-university

## Назначение агента

ИИ-агент, который помогает вести учёт продуктов и домашних запасов: фиксирует покупки, следит за сроками годности и подсказывает, что нужно использовать в первую очередь. Основная цель — сократить количество просроченных продуктов и вовремя напоминать о пополнении запасов.

## Язык программирования

Проект разрабатывается на **C#**. Взаимодействие с пользователем планируется через консольный интерфейс, данные хранятся локально в файле `data.json`.

## Планируемые возможности

- Добавление продукта с указанием количества, категории и срока годности.
- Просмотр списка продуктов, у которых срок годности истекает в ближайшие N дней.
- Отметка продукта как использованного или выброшенного со списанием из запасов.
- Группировка запасов по категориям (`dairy`, `grocery`, `frozen` и т. п.).
- Поиск продукта по названию и просмотр остатков.

## Примеры запросов и ожидаемые результаты

### Пример 1. Добавление продукта

**Запрос пользователя:**
> Добавь в запасы 2 литра молока, срок годности — 12 мая, категория «молочное».

**Ожидаемый результат:**
Агент создаёт запись с уникальным `id`, сохраняет её в `data.json` и выводит подтверждение:
> Добавлено: #14 «Молоко» — 2 л, категория: молочное, срок годности: 12.05.

### Пример 2. Проверка сроков годности

**Запрос пользователя:**
> Что у меня скоро испортится?

**Ожидаемый результат:**

Агент выбирает из `data.json` только продукты, у которых срок годности истекает в ближайшие 3 дня, и выводит их отсортированным списком:
Скоро истекает срок годности:
#14 Молоко — 2 л (осталось 2 дня)
#9 Йогурт — 4 шт. (истекает завтра)
#21 Сыр — 300 г (истекает сегодня)

## Технологический стек (полный)

- **IDE / Редактор**: Visual Studio Code (с расширением C#)
- **Язык и версия**: C# 12 (жестко задана в `.csproj` через `<LangVersion>`)
- **Среда выполнения**: .NET 10.0 (LTS)
- **Менеджер зависимостей**: NuGet
- **Используемые библиотеки**: `System.Text.Json` (входит в стандартную библиотеку .NET)
- **Средства хранения данных**: Локальный файл `data.json`
- **Отладчик**: Встроенный отладчик VS Code
- **Линтер**: Roslyn Analyzers (встроенные анализаторы .NET)
- **Форматтер**: `dotnet format`

## Подготовка окружения
1. Установите **.NET SDK 10.0** (проверка: `dotnet --version`).
2. Клонируйте репозиторий и перейдите в папку:
  ```bash
   git clone <url-репозитория>
   cd AI-agent-university/src
  ```

Восстановите зависимости:

> dotnet restore

Запуск

Находясь в дирректории AI-agent-university/src выполните:

> dotnet run --project AiAgentUniversity.App

Штатное завершение: команда exit, quit или сочетание клавиш Ctrl+D (EOF).

Назначение команд

Команда	Назначение

- add <название> <кол-во> <ед> <категория> <дата>	Добавить продукт. Дата в формате yyyy-MM-dd или dd.MM.yyyy.
- list	Показать все запасы.
- expiring <дни>	Показать продукты, истекающие в ближайшие N дней.
- category <категория>	Показать продукты выбранной категории.
- find <подстрока>	Поиск продукта по названию.
- consume <id> <кол-во>	Списать продукт (использовано/выброшено).
- help	Показать справку.

Хранение данных

Состояние хранится в JSON-файле data.json в рабочем каталоге. После каждой команды, изменяющей данные (add, consume), файл перезаписывается. При запуске данные считываются обратно. Файл исключён из Git через .gitignore, так как содержит пользовательские данные. Некорректные числовые значения (NaN, Infinity) отсекаются на этапе парсинга и не повреждают состояние.

Проверки кода

Форматтер (проверка стиля)(находясь в дирректории AI-agent-university/src):

> dotnet format --verify-no-changes

Линтер (анализаторы Roslyn):

> dotnet format analyzers --verify-no-changes

Примеры диалога

Пример 1. Успешный сценарий

> add Молоко 2 л молочное 12.05.2026

Добавлено: #1 «Молоко» — 2 л, категория: молочное, срок годности: 12.05.2026.

> consume 1 1

Списано 1 л «Молоко». Осталось: 1 л.

> exit

Завершение работы. До свидания!
Пример 2. Обработка ошибок ввода (включая NaN)

> consume 1 NaN

[ошибка] некорректное количество: «NaN».

> add Вода NaN л напитки 2026-10-30

[ошибка] некорректное количество: «NaN».

> foo

[ошибка] неизвестная команда «foo». Введите `help`.

> list

Текущие запасы:
  #1 «Молоко» — 1 л, категория: молочное, срок: 12.05.2026 (осталось ... дн.)
Ошибочный ввод не завершает программу и не повреждает состояние. Состояние сохраняется при последующих корректных операциях.
